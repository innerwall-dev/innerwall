## Release notes (v0.1.0)

**Innerwall v0.1.0** is the first release: one control-plane binary with the operator console embedded, one Postgres, and a Linux agent.

- **Enrollment and identity:** token-gated enrollment with no trust-on-first-use window. Scoped, expiring, revocable provisioning tokens stored only as digests. One URI SAN per credential. 24-hour credentials renewed automatically.
- **Policy sync:** one mutually authenticated stream per agent: a snapshot per stream, deltas within it, versions that advance only on a rendered change, full-jitter reconnects.
- **Flows:** inbound connections aggregated at the agent, reported on their own RPC, peers resolved at ingest, with evidence gaps recorded wherever the agent knows evidence was lost.
- **Policy, simulation, enforcement:**
  - live authoring with conditional writes and dry-run renders;
  - simulation as the exact enforced ruleset;
  - enforcement into one owned nftables table in single kernel transactions, persisted before it is applied, with stable rule attribution and a local kill switch;
  - inbound only.
- **Operator surface and console:** one TLS-only listener, single-operator authentication, an origin guard on every write. The flow map, fleet, workload detail, policy editor, and simulation review with an acknowledgment-gated promotion.

**Fixed before release:** two independent conformance audits drove these fixes (#23, #24, #25 and this PR):
- persist-before-apply acknowledgement;
- stable connection-mark attribution;
- a bounded open flow window;
- strict identity parsing;
- a bounded login throttle;
- a patched Go toolchain with a govulncheck gate;
- bundled third-party licenses;
- no real secrets in screenshots;
- a migration immutability guard;
- a decision record that states only what ships;
- an image that builds.

**Known limitations:**
- The server-side evidence guard, the workload deny-list, and clone detection are not built.
- `serve` has no flag for the aggregation window.
- Linux only, inbound only, one operator.

The full list is in [CHANGELOG.md](CHANGELOG.md).
